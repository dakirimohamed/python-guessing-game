## 🎮 About the Game

The computer chooses a random number between **0 and 10**. Your mission is to guess it!

### 🕹️ How to Play

- 🎲 Enter a number between 0 and 10.
- ⬆️ **Too high!** Try a smaller number.
- ⬇️ **Too low!** Try a bigger number.
- 🏆 Guess correctly to win!

## ✨ What I Practiced

- 🧠 Variables and user input
- 🎲 Random numbers with `random.choice()`
- 🔄 `while` loops
- 🔀 `if` and `elif` statements
- 🔢 Converting input with `int()`

## 🚀 How to Run

1. Install Python.
2. Download `guessing_game.py`.
3. Open a terminal in the project folder.
4. Run this command:

```bash
python guessing_game.py
```

## 💻 Example Gameplay

```text
Guess the Number 'From 0 to 10': 9
Too high
Guess again: 4
Too low
Guess again: 7
Congratulations! You guessed the correct number!
```
